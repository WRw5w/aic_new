## 2. 制胜链路（一路怎么涨上来的）

```
单模型 LoRA 天花板  ~76.1
  └─ + cleanlab 去噪            76.61   （唯一破 76.1 的单一机制）
       └─ + mixup0.2           77.13   clmix = 全项目最强单模型

                 └─ SWA 8点     78.42   clmixsoup4  (ep05-12)
                      └─ SWA 9点 78.59  clmixsoup3  (ep04-12)
                           └─ SWA 10点 78.63  clmixsoup5 (ep03-12) 🏆 峰值
```

**SWA 跨度规律(已钉死峰值)**：同一条 clmix_long(ep01–12) 轨迹，零训练只换 soup 窗口——
3点 77.27 → 7点 78.26 → 8点 78.42 → 9点 78.59 → **10点 78.63(峰)** → 11点 78.49↓ → 12点 78.30↓↓。
- **峰值在 ep03–12(10点)**：每加一个**后段**早期 epoch ≈+0.16(单调上行),但加到 **ep02/ep01(极早 warmup)反而掉头**(11点 −0.14、12点 −0.33)。
- **最优窗口 = 丢掉前 2 个 warmup epoch(ep01-02)、平均其余全部**。机制:cosine 退火下 ep03 起已进同一收敛盆地、纳入扩大平均范围降方差;ep01-02 LR 太高、离盆地远,拖坏平均。**前提是同轨迹(mode-connected)**——跨 seed 会崩(§4)。

## 4. 已坐实的结论

### ✅ 有效
1. **推理两杠杆**：满均衡 **+2.9pt**、满 TTA **+1.1pt**。均衡强度 0.75≈1.0（77.73 vs 77.69，差在噪声内），不必细调。
2. **cleanlab 去噪**是唯一抬过单模型 76.1 天花板的单一机制（76.61）。每类自信度阈值剪枝 > kNN 一致性。
3. **mixup0.2** 与去噪正交叠加 → clmix 77.13。
4. **同轨迹 SWA / Model Soup**：把单模型推到 78+。**fet_soup 77.10**（FET 单 76→汤 77.1，独立证明 soup 在干净测试集真涨 +1.1）。跨度越宽越好。

### ❌ 证伪 / 走死
| 方向 | 榜分 | 结论 |
|---|---:|---|
| **跨 seed soup** | cl2soup 73.96 / cl4soup 70.65 | **暴跌**，mode-connectivity 断裂，彻底封死 |
| 多样化汤 | soup_v2 76.83 / soup_v3 77.43 | 均 < uniform 77.69，"多样性是杠杆"被推翻 |
| 贪心汤 | soup_greedy 75.33 | 塌缩到单模型 |
| 长训练 | run60_ep60 75.62 / swa_run60 75.67 | 轮次不是杠杆 |
| FET 架构线 | fet_iter1 76.16 等全 ~76 | val 0.929 首超 soup 却**零转化**，瓶颈是特征+噪声非架构 |
| 鲁棒损失 | sce 74.31 / apl 70.83 | 差 |
| DoRA | dora 74.80 / dora16 74.25 | 差 |
| 特征用法 | fuse4 75.53 / fuse6 75.52 / attnpool 75.81 | **全军覆没**，换花样用冻结特征无用 |
| relabel | clrelabel 74.88 | relabel 引噪 |
| OT/课程 | ot 74.70 / otknn 69.26 / curriculum 74.98 | 差 |
| 5 信号线 | ≤75.66 | 早封板 |

### 🔑 关键认知
- **val 在 0.92–0.93 段完全不预测榜分**（cleanlab val 中游却榜分最高；fuse6 val 最高 0.9263 却榜分垫底 75.52）。多次证伪，**只认榜分**。
- **瓶颈 = 冻结 B/32 特征质量 + 不可约噪声**，不是头部架构/容量。唯一钥匙是**去噪**。
- **soup 铁律：只在同一次训练的相邻 epoch 快照间做**，绝不跨 seed / 跨配方。

## 5.5 创造性方向探索（2026-06-22，跳出"再调 SWA"）

边际见顶(10点仅比9点+0.04)后,广泛找机制不同的新杠杆。已落地/已验:

- **方向 A：转导式均衡推理(Sinkhorn-OT)= 负结果**。现 `fit_uniform_bias`(softmax温度1+列约束)**已几乎是 OT 最优解**:完整双约束 Sinkhorn 温度1 与之只差 145/24967(0.6%);温度0.5 略紧(std 1.16→0.97,改判171);更低温(0.25/0.1)未收敛反而变差;硬均衡分配实现有 bug 弃。**结论:均衡杠杆到顶,没藏免费分。** 工具留用:`tta_predict --save-logits` + `tools/balance_transductive.py`。
- **方向 B/C/D（待做,需重训+论文核对）**：B=CLIP 文本塔 prompt 头(CoOp,但无语义类名→novelty 打折,退化为余弦原型头);C=半监督回收被丢的~8%(DivideMix/FixMatch 一致性正则,机制最不同);D=SOP 稀疏过参数化吸噪。**优先级 C>B>D**,等 clmixsoup8 出分判断"加长轨迹"是否有效后再投 11h。

- **v13/v14：更长轨迹(15ep)更宽 SWA**。v13 重训 clmix 16ep(early-stop@ep15,val峰ep11),得 ep01-15。按"丢前2 warmup"规律出 3 候选(均 next_queue,待出分,与 78.63 比):

  - clmixsoup9 = ep04-15(12点)、clmixsoup10 = ep05-15(11点) ← 定 warmup 截断
